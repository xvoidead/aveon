# авеон

Музыкальный плеер для Windows. Когда в звонке Discord кто-то говорит, музыка уходит «в бочку»:
глухо и гулко, как из-за стенки. Как только собеседники замолкают, звук возвращается.

## Запуск

```
npm install
npm start
```

Нужны Windows 10/11 и Node.js 20+. Если после `npm install` Electron не запускается, выполни
`node node_modules/electron/install.js`.

## Что умеет

- **Эффект в звонке.** Срез высоких частот, гул около 170 Гц, короткие переотражения. Глухость,
  гулкость и громкость настраиваются. Есть режим «просто тише».
- **Свои файлы:** mp3, flac, ogg/opus, m4a, wav. Клик по названию, артисту или обложке открывает
  редактор тегов с поиском тегов и обложки в каталоге iTunes. Файлы не меняются, правки хранятся
  в приложении.
- **Сервисы:** SoundCloud (client_id находится автоматически), Яндекс Музыка (OAuth-токен), Spotify.
  Из Spotify берутся лайки и плейлисты, звук — через Яндекс Музыку или SoundCloud: Spotify не отдаёт
  аудио сторонним плеерам.
- **Альбомы** из треков любых источников, порядок меняется перетаскиванием.
- **Текст песни** из [LRCLIB](https://lrclib.net). Текущая строка подсвечивается и плавно
  прокручивается, клик по строке перематывает трек.
- **Статистика:** время прослушивания по дням, топ-10 треков месяца, артисты месяца.
- **Продолжение с того же места.** После перезапуска трек стоит на паузе там, где ты остановился.
- **Палитра из обложки:** фон, акцент и бочка плавно перекрашиваются под текущий трек.
- Интерфейс строчными буквами. Названия треков можно оставить как есть в настройках.

## Как работает эффект в звонке

`native/DuckMon.cs` — маленький монитор на Windows Core Audio. При первом запуске он собирается
встроенным в Windows компилятором .NET Framework. Монитор 30 раз в секунду читает уровень звука
Discord и понимает, что ты в голосовом канале (Discord держит микрофон). Discord для эхоподавления
захватывает весь звук колонок, поэтому из его уровня вычитается звук остальных программ: остаток —
это голоса собеседников.

Твой голос плеер слушает сам, только пока ты в звонке. Работают шумоподавление и эхоподавление
Chromium, учитывается только полоса голоса 250–3800 Гц, звук должен быть громче порога и длиннее
120 мс. Шум, клавиатура и музыка из колонок речью не считаются. Звук никуда не записывается
и не отправляется.

## Где хранятся данные

`%APPDATA%\авеон`: настройки (`config.json`, токены зашифрованы через DPAPI Windows), альбомы,
свои теги и обложки, статистика, место остановки. Если раньше стояла версия «Тише», её данные
переносятся автоматически.

## Горячие клавиши

Пробел — пауза, ←/→ — перемотка на 5 с, Ctrl+←/→ — трек назад/вперёд, ↑/↓ — громкость,
M — без звука, S — перемешать, R — повтор, L — текст песни, Ctrl+F — поиск, Ctrl+, — настройки.
